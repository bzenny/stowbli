# STOWBLI

**A minimal wallet. On your phone.**

STOWBLI is a small, open-source, self-custody crypto wallet.

The wallet is created and controlled locally on the user's phone.

## Principles

- Your keys, your wallet.
- No STOWBLI account.
- No STOWBLI server required for custody.
- No subscription.
- No analytics.
- No advertising.
- No fee for creating or holding a wallet.
- Transactions are signed locally.
- Network fees apply only when required by the blockchain.

## v0.1

STOWBLI starts small:

1. Create or import a wallet
2. Secure the wallet locally
3. View address and balance
4. Receive
5. Send
6. Backup / recover

The first implementation targets EVM-compatible networks.

STOWBLI does not operate its own blockchain.
